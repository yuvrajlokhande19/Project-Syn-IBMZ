## 🎯 Deliverables & Scripts
1. **`data_generator.py`**:
   - Generates simulated hospital IoT streams (grid voltage, fuel level, water pressure) and flood indices.
   - Computes `hmac_signature` using a secret key with Python's native `hmac` + `hashlib.sha256`.
2. **`attack_injector.py`**:
   - Simulates cyber threats by intentionally altering sensor metric values without a matching HMAC signature, or corrupting the signature itself.
3. **`train_snap_ml.py`**:
   - Trains a Random Forest Classifier on simulated telemetry to detect infrastructure resource depletion.
   - Exports the trained model to `artifacts/model.pmml` or `.pkl` for cross-endian execution on IBM LinuxONE `s390x`.
4. **`routing_algorithm.py`**:
   - Deterministic graph routing algorithm (Dijkstra/hard rules) calculating safe ambulance corridors and ICU load shedding.
   - **Crucial Rule:** The algorithm makes the life-safety decision; generative AI never decides routes!
